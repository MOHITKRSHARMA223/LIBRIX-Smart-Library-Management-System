# User Manual

## Signing in

The development demo accepts `admin` / `admin123` and `student` / `student123`. These credentials are for local demonstration only.

## Roles

Administrators and librarians see operational modules. Students see the separate browsing and personal-loans navigation. A `UserSession` enforces the role boundary in the application layer.

## Dashboard

The dashboard shows books, availability, active members, overdue loans, and recent activity. The current demo values are clearly marked as demo-mode data until MySQL repositories are connected.
